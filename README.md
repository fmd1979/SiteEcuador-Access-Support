# SiteEcuador Access & Support

Plugin local de Moodle desarrollado por **SiteEcuador S.A.S.**

Personaliza el acceso con video de YouTube, etiqueta de usuario o cédula, controles para visualizar contraseñas y una página de soporte con afiche y contactos configurables.

## Compatibilidad
- Objetivo: Moodle 5.3+, tema Boost.
- Componente interno: `local_apclogin`.
- Ruta de instalación: `local/apclogin`.
- Mantener el componente y directorio existentes para actualizar APC Login sin perder configuración.

## Funcionalidades
- Video YouTube configurable y botón de sonido.
- Textos de acceso personalizables.
- Botones para mostrar y ocultar contraseñas.
- Página de soporte y Call Center.
- Afiche y contactos configurables; panel lateral opcional.
- Diseño adaptable a móviles.

## Instalación
1. Descargar el paquete de distribución e instalarlo desde Administración del sitio → Plugins → Instalar plugins.
2. Completar la actualización y purgar cachés.
3. Configurar en Plugins locales → SiteEcuador Access & Support.
4. Verificar las páginas de acceso, cambio de contraseña y soporte.

**Seguridad:** sustituir visualmente el enlace de recuperación no deshabilita la recuperación de contraseña a nivel de servidor.
